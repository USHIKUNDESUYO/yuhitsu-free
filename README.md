## 起動する

Windows 10・11の64ビットPCで、ZIPをすべて展開し、start.cmdを開いてください。既定のブラウザーで http://127.0.0.1:4319 が開きます。起動に必要なNode.jsを同梱しているため、追加のインストールは不要です。

最初は「サンプルを入れる」で架空データを読み込み、結果の出力まで確認してください。同じ画面内のモード切替では、入力と結果を保持します。画面を閉じる、再読み込みする、別のタブで開く場合は引き継ぎません。入力を自動保存する機能はないため、終了や再読み込みの前に必要なExcel、ZIP、HTML、CSVを出力してください。

狭い画面では表だけを横スクロールできます。表を選んで左右キーで移動し、HomeとEndで両端を確認してください。

終了するときは画面を閉じ、stop.cmdを開きます。他のソフトが4319番のポートを使用している場合は起動を中止します。利用中のソフトを勝手に終了する処理はありません。

## 端末内で処理する

会計データの集計、調書出力、照合、画像・PDFの読み取りはPC内で処理します。読み取りに必要な日本語・英語のデータも同梱しています。クラウドAIへの送信機能は、この配布版では提供しません。

端末内AIは初期状態でOFFです。ONにすると、初回にAIモデルを外部の配信元から取得します。モデルの取得にはネット接続と空き容量が必要です。入力した会計データや証憑はモデル配信元へ送信しません。モデル取得先には接続元のIPアドレスなどの通信情報が伝わります。

端末内AIにはWebGPU対応のChromeまたはEdgeが必要です。GPUの対応やメモリが不足する場合は、定型の下書きを使用してください。モデルの種類と条件はmodel-notices.mdに記載しています。

## 別端末で確認する

device-checkには、別端末で架空サンプルを試す手順、環境情報を記録するPowerShellスクリプト、通信しないWebGPU確認画面を同梱しています。結果は端末内へ保存し、自動送信はしません。手元にある別のPCで確認する場合に、device-check/README.mdを参照してください。

## v0.1.6の草案

端末内AIが返すのは、未確認の原因と確認資料を表す短い語句の二組です。確認資料は提示した候補に限定し、アプリが二つの仮説文と資料名の留意点を組み立てます。入力された手続・結果・数値は、引き続き端末側で保持します。

書式例と再生成の指示も見直しました。既知の不自然な日本語と、同じ確認資料の繰り返しも検査します。Windows 11・AMD Radeon 860M・Edge 155の1台で、架空サンプル14件の最終草案を確認しました。13件は初回に採用し、1件は誤記を拒否した後の再生成で採用しています。計測条件と時間は[モデルの実機確認](model-notices.md#v016の実機確認)を参照してください。

AIの原因候補に「借入返入」がある応答は採用しません。「借入返済」と書くよう一度だけ再生成を求めます。入力の原文は変更しません。再生成でも解消しなければ、定型草案へ切り替えます。

定型草案の句点の重なりと、会社説明に関する注意の重複を修正しました。AIの原因候補は未確認の一般例なので、担当者が実際の状況と原資料との対応を確認してください。
